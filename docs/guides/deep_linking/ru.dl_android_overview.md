Этот раздел содержит инструкции для разработчика Android по настройке OneLink (глубокой связи и отложенной глубокой связи) для работы в приложении.

В настройке задействовано несколько этапов:

1. [Первоначальная настройка приложения](dl_android_init_setup)
2. [Единая глубокая связь (UDL)](dl_android_unified_deep_linking)
3. [Optional] [Расширенные отложенные углубленные ссылки](dl_android_ocds_ddl) с использованием частей GCD API.

**Примечание:** Клиенты, уже использующие OneLink, могут использовать [устаревшие методы] (https://dev.appsflyer.com/hc/docs/dl_android_gcd_legacy) для глубокой связи и отсрочки глубокой связи вместо UDL.
