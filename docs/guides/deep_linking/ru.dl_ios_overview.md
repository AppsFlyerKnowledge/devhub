Этот раздел содержит инструкции для разработчика iOS, чтобы установить OneLink (глубокие ссылки и отложенные глубокие ссылки) для работы в приложении.

В настройке задействовано несколько этапов:

1. [Первоначальная настройка приложения](dl_ios_init_setup)
2. [Единая глубокая связь (UDL)](dl_ios_unified_deep_linking)
3. При необходимости [расширенная глубокая ссылка отсрочка](dl_ios_ocds_ddl), используя части GCD API.

**Примечание:** Клиенты, уже использующие OneLink, могут использовать [устаревшие методы] (https://dev.appsflyer.com/hc/docs/dl_ios_gcd_legacy) для глубокой связи и отсрочки, а не UDL.
