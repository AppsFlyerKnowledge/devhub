SDK предлагает различные методы сохранения приватности для управления данными, переданными на AppsFlyer из вашего приложения. Эти методы помогают обеспечить, чтобы частная информация не подвергалась раскрытию без согласия пользователя и чтобы она поддерживалась в соответствии с соответствующими законами и положениями о защите данных.

## Методы сохранения конфиденциальности: Когда, кто и что нужно отправить

SDK позволяет вам управлять информацией, которую вы отправляете на AppsFlyer путем предоставления методов:

- Когда отправлять данные уровня пользователя
- Кто получает данные уровня пользователя
- Какие данные для отправки

### Когда отправлять данные уровня пользователя

SDK посылает информацию о установках приложения и внутри-приложениях на AppsFlyer сразу же после вызова метода `start`. Методы сохранения конфиденциальности влияют на доступность определенных данных событий уровня пользователя в зависимости от того, вызываются ли они до или после вызова метода `start`.

Когда вызывается `start` в первый раз, SDK отправляет событие установки AppsFlyer, а также параметры, необходимые для привязки установки к правильному источнику носителя. Поэтому использование методов перед вызовом `start` может помешать AppsFlyer правильно присвоить значение события установки.  
Таким образом, если вы хотите, чтобы атрибуция имела место, не вызывайте методы приватностного сохранения перед методом `start`. Вместо этого вызывайте их только после того, как событие установки было отправлено на AppsFlyer. Такой подход гарантирует, что события пользователя в приложении остаются приватными, пока ещё могут иметь место атрибуции установки.

### Кто получает данные уровня пользователя

Рекламные сети и Сети Самоотчетности (SRN), которые вы сотрудничаете, получают информацию уровня пользователя для атрибуции и оптимизации. Тем не менее, вы можете использовать фильтр для совместного использования партнеров, чтобы ограничить обмен данными с некоторыми или всеми партнерами в соответствии с предпочтениями конечных пользователей.

### Какие данные для отправки

SDK предлагает несколько методов для защиты данных уровня пользователя. Метод анонимизации пользователя удаляет или хэширует все идентификаторы уровня пользователя, в то время как другие методы удаляют только определенные типы идентификаторов.
