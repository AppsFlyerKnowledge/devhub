Выгрузите большую часть интеграции AppsFlyer SDK на AppsFlyer's SDK MCP сервер с помощью инструмента программирования, работающего на AI, такие как OpenAI Codex, GitHub Copilot, или Cursor. Это руководство применимо и к проектам приложений **iOS**, и **Android**.

## Шаг 1: Приготовьтесь

- Ваш [**AppsFlyer Dev ключ**](https://support.appsflyer.com/hc/en-us/articles/207032066-Basic-SDK-integration-guide#retrieve-the-dev-key).
- Ваш проект (iOS или Android).
- Ваш идентификатор приложения:
  - **Android**: имя пакета для вашего приложения (например, `com.example.myapp`).
  - **iOS**: ID вашего приложения или ID App Store ID (например, `id123456789`).
- Инструмент для кодирования, работающий на AI, установлен и настроен для вашего проекта.
- IDE установлен для синхронизации, сборки и запуска приложения:
  - **Android**: Android Studio.
  - **iOS**: Xcode.

## Шаг 2: Добавьте AppsFlyer SDK MCP сервер

Сервер AppsFlyer SDK MCP одинаковый для обеих платформ. Единственными измененными значениями являются переменные среды `DEV_KEY` и `APP_ID`. Выберите ниже инструкции для вашего инструмента ИИ кодирования.

### Cursor

1. В Курсоре, перейдите на **Курсор** > **Настройки…** > **Настройки курсора** > **Инструменты и MCP**.

2. Нажмите **Новый MCP сервер**.

3. Добавьте новую запись в MCP сервер в **mcp.json**, используя `APP_ID` и `DEV_KEY`:

   ```json
   "appsFlyer-sdk-mcp": {
     "command": "npx",
     "args": [
       "-y",
       "@appsflyer/sdk-mcp-server"
     ],
     "env": {
       "APP_ID": "<your-app-identifier>",
       "DEV_KEY": "<your-dev-key>"
     }
   }
   ```

4. Перезапустите курсор для применения изменений.

5. В Курсоре, перейдите на **Курсор** > **Настройки…** > **Настройки курсора** > **Инструменты и MCP**.

6. Найдите добавленную запись MCP сервера.

7. Подтвердите, что он помечен **зеленой точкой**. Это указывает на работу MCP сервера.

### Код Claude

1. В терминале вашего проекта, запустите следующую команду Claude Code с помощью `APP_ID` вашего приложения и `DEV_KEY`:

   ```bash
   claude mcp добавить --transport stdio appsFlyer-sdk-mcp \
     -e APP_ID=<your-app-identifier> \
     -e DEV_KEY=<your-dev-key> \
     -- npx -y @appsflyer/sdk-mcp-server
   ```

2. Перезапустите Claude Code для загрузки нового сервера.

3. Подтвердите, что **appsFlyer-sdk-mcp** указан и подключен (запустите `claude mcp list`).

### Кодекс

1. В Codex перейдите в **Настройки** > **MCP Серверы**.
2. Нажмите **+ Добавить сервер**.
3. В поле **Имя** укажите имя сервера.
4. В **Команде запуска** введите `npx`.
5. В **аргументах** введите следующие аргументы, каждая из которых в отдельном поле:
   - `-y` (установить и обновить MCP каждый запуск).
   - `@appsflyer/sdk-mcp-server` (имя сервера, указанного в реестре NPM).
6. В **Переменные окружения** добавьте переменные `DEV_KEY` и `APP_ID` и их значения для вашего приложения.
7. Перезапустите Codex для загрузки нового **MCP сервера**.
8. В Codex откройте **Настройки** > **MCP Servers** и подтвердите, что **AppsFlyer SDK MCP сервер** включен.

### GitHub Copilot (Android only)

> **Примечание:** Эти шаги GitHub Copilot применяются к проектам **Android** в Android Studio. Для iOS, используйте **код** или **Курсор** выше.

1. В Android Studio, откройте **Настройки** и перейдите в **Инструменты** > **GitHub Copilot** > **Модельный контекстный протокол (MCP)**.

2. В настройках **Model Context Protocol (MCP)** выберите **Configure**.

3. В **mcp.json** добавьте настройки MCP сервера AppsFlyer SDK, используя `APP_ID` и `DEV_KEY`:

   ```json
   "appsFlyer-sdk-mcp": {
     "command": "npx",
     "args": [
       "-y",
       "@appsflyer/sdk-mcp-server"
     ],
     "env": {
       "APP_ID": "<your-app-identifier>",
       "DEV_KEY": "<your-dev-key>"
     }
   }
   ```

4. Перезапустите Android Studio для применения изменений.

5. В Android Studio, откройте **GitHub Copilot Chat**.

6. В нижней части панели чата Copilot выберите из списка агентов **Сотрудник**.

7. Нажмите кнопку **Инструменты MCP**.

8. В диалоговом окне **Настроить инструменты** для инструмента **appsFlyer-sdk-mcp** нажмите **Start**.

9. Чтобы подтвердить, что сервер запущен, откройте GitHub Copilot **MCP Log**. В отображаемой панели MCP журнала, вы должны видеть, что сервер запущен.

## Шаг 3: Предложить ИИ интегрировать SDK

1. В чате наберите **Интегрируйте AppsFlyer SDK с помощью MCP**.
2. Просмотрите изменения в коде вашего редактора и убедитесь, что интегрированный код соответствует требованиям вашего проекта и стандартам кодирования. Если что-то выглядит незнакомым, задайте последующие вопросы ИИ.

## Шаг 4: Предложить ИИ проверить интеграцию

1. Откройте ваш IDE (Android Studio для Android, Xcode для iOS).
2. Синхронизация проекта.
3. Создайте и запустите приложение.
4. В чате попросите ИИ проверить интеграцию AppsFlyer SDK. Агент AI использует инструмент MCP для считывания журналов с вашего устройства и подтверждения успеха интеграции.
   - Если обнаружены ошибки, инструмент объяснит, что пошло не так, и предложит исправления ошибок.
   - Если все выглядит хорошо, вы увидите подтверждение успешной интеграции.
