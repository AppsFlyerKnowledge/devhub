Данные преобразования описывают канал(ы), через которые пользователи попали в ваше приложение.

SDK позволяет вам получить доступ к данным в реальном времени для каждой сессии приложения. Как только данные будут доступны, вы можете:

- Настройте логику и поток вашего приложения на основе возвращаемых данных
- Отправлять данные на серверы для дальнейшей обработки
