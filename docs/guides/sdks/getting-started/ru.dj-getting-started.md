Вы просто предоставляете некоторые учетные данные и варианты настройки, а мастер генерирует фрагменты кода для копирования и вставки в проект. После этапа реализации, вы будете следовать руководству по тестированию и устранению неполадок.

Для Разработчика требуется поездка:

- [Ваш идентификатор приложения ](https://support.appsflyer.com/hc/en-us/articles/207377436-Adding-an-app-to-AppsFlyer#enter-app-details)
- [Ваш Dev Ключ от AppsFlyer ](https://support.appsflyer.com/hc/en-us/articles/207032066-Basic-SDK-integration-guide#retrieve-the-dev-key)
- [AppsFlyer v2 authentication token ](https://support.appsflyer.com/hc/en-us/articles/360004562377-Managing-API-and-Server-to-server-S2S-tokens#reaching-the-tokens-page)  
  (Обязательно только если вы хотите следить за процессом автоматического тестирования)

- Операционные системы
  - Android

  - Реакция
  - Флаттер
- Потоки
  - SDK [installation](https://dev.appsflyer.com/hc/docs/sdk-installation) и [integration](https://dev.appsflyer.com/hc/docs/sdk-integration)
