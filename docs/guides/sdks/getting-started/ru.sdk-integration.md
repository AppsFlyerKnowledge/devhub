Инструкции по интеграции AppsFlyer SDK для различных платформ. Интегрируя SDK, вы получаете [атрибут приложения](https://support.appsflyer.com/hc/en-us/articles/207447053#what-is-attribution%C2%A0) вне компьютера.

Интеграция SDK состоит из:

- Инициализация SDK
- Запуск SDK

## Прежде чем начать

Убедитесь, что вы [установили SDK](doc:sdk-installation).
