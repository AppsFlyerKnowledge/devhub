Android SDK 6 is AppsFlyer's previous major SDK version, using automatic session start on foreground. If you're starting a new integration, use [Android SDK 7](doc:android-sdk-7) instead.

## In this section

- [Integrate SDK](doc:integrate-sdk-android-6) — Add the SDK to your project and configure it.
- [In-app events](doc:in-app-events-android-6) — Log user actions and purchases.
- [Preserve user privacy](doc:preserve-user-privacy-android) — Configure privacy-related SDK behavior.
- [Features](doc:features-android-6) — Push notifications, uninstall measurement, DMA consent, and OAID.
