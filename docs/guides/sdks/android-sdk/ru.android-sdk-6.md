Android SDK 6 является основной версией AppsFlyer, использующей автоматический запуск сессии на передний план. Если вы запускаете новую интеграцию, используйте [Android SDK 7](doc:android-sdk-7).

## В этом разделе

- [Интеграция SDK](doc:integrate-sdk-android-6) — Добавьте SDK в свой проект и настройте его.
- [События в приложении](doc:in-app-events-android-6) — Записывать действия пользователей и покупать.
- [Сохранить конфиденциальность пользователя](doc:preserve-user-privacy-android) — настроить поведение, связанное с приватностью.
- [Features](doc:features-android-6) — Push-уведомления, измерения удаления, согласия DMA и OAID.
