Android SDK v7 дает вам явный контроль над тем, когда SDK запускает сессию, выравнивает Android и iOS API, и позволяет вам объявить параметры строительного времени в JSON файле, чтобы вы могли строить более предсказуемые интеграции, учитывающие согласие.

## Что нового в версии 7

SDK v7 дает вам явный контроль над тем, когда SDK запускает сеанс. В предыдущих версиях SDK запускался автоматически на переднем плане. Это затруднило проведение сессии при таких условиях, как согласие СКП, или идентификатор пользователя, который должен быть включен в событие установки.

v7 заменяет автоматический стартап на слушателя готовности сеанса. Вы регистрируете его после `init()`, затем вызываете `start()` внутри него, или после выполнения условий предварительного запуска.

Эта версия также устраняет давние несоответствия между Android и iOS. Установка, глубокие связывающие API и конфигурация SDK теперь выравниваются на обеих платформах.

Новая конфигурация на основе файлов `af_init_config.json` в вашей папке активов, позволяет объявить константы build-time без установки их в код.
