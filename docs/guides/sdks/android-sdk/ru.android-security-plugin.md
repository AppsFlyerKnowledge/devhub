## Общий обзор

Этот документ описывает шаги интеграции для модуля AppsFlyer Advanced Security.

## Минимальные версии

Убедитесь, что ваш проект соответствует следующим минимальным версиям для совместимости с модулем Advanced Security:

### Обновления совместимости: AppsFlyer Android SDK и модуль безопасности

- Модуль безопасности v1.x.x (последний `1.3.4`) совместим с [AppsFlyer Android SDK](https://support.appsflyer.com/hc/en-us/articles/115001256006-AppsFlyer-Android-SDK-release-notes) `6.15.2 – 6.17.3`.
- Модуль безопасности v2.x.x (`2.2.1`) совместим только с AppsFlyer Android SDK версией `6.17.4` и выше.

Пожалуйста, убедитесь, что версии, которые вы интегрируете, следуют выше диапазонам совместимости, чтобы избежать проблем с сборкой или исполнением.
Если вы планируете обновить SDK до `6.17.4+`, не забудьте обновить модуль безопасности до версии 2.0.0 и выше.
С другой стороны, если вы используете SDK версии ниже 6.17.4, пожалуйста, продолжайте использовать модуль безопасности v1.x.x (последний `1.3.4`).

## Перед началом

1. Пожалуйста, присылайте нам все хэши сертификатов (SHA-256) всех сертификатов, с которыми Вы подписываете приложение. <br>Это включает отладку и выпуск хэшей сертификатов. The certificate hashes are needed to pre-build the version of the security module that your app will use.</br>
   Инструкции о получении сертификатов можно найти на сайте [here](#generating-a-sha256-fingerprint). </br>

2. Обязательно запросите у вашего контактного лица следующую информацию на AppsFlyer:
   1. Имя репозитория Maven
   2. Маркер авторизации Maven
   3. Последняя версия модуля Advanced Security, которая была создана для вашего приложения.

## Интеграция

Пожалуйста, следуйте следующим двум шагам. После завершения и загрузки зависимости AppsFlyer Android SDK будет использовать модуль автоматически.

### Шаг 1

Артефакты хранятся в инфраструктуре AppsFlyer .
Добавьте ваш выделенный репозиторий на AppsFlyer Maven в качестве источника репозитория в файл `settings.gradle` или `settings.gradle.kts`:

```groovy
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode. AIL_ON_PROJECT_REPOS)
    repositories {
        mavenCentral()
        maven {
           url 'https://art. ж-сдк. o/security-sdk/maven'
           credentials(HttpHeaderCredentials) {
               name = 'Authorization'
               // получение токена из переменной окружения
               value = 'Bearer ' + Система. etenv("APPSFLYER_AUTH_V2_TOKEN")
           }
           authentication {
               header(HttpHeaderAuthentication)
           }
           content {
               includeGroup "com. ppsflyer. ecurity"
           }
        }
        // другие репозитории. .
    }
}
```

```kotlin
dependencyResolutionManagement {
    repositoriesMode.set(RepositoriesMode. AIL_ON_PROJECT_REPOS)    
    repositories {
        mavenCentral()
        maven {
          url = uri("https://art. ж-сдк. o/security-sdk/maven")
          credentials(HttpHeaderCredentials::class) {
              name = "Authorization"
              // получаем токен из переменной окружения
              value = "Bearer ${System. etenv("APPSFLYER_AUTH_V2_TOKEN")}"
          }
          authentication {
              create("header", HttpHeaderAuthentication::class. ava)
          }
          content {
              includeGroup("ком. ppsflyer.
          }
        }
        // другие репозитории. .
    }
}
```

`APPSFLYER_AUTH_V2_TOKEN` Это API V2 токен, необходимый для аутентификации и авторизации репозитория. Вы можете получить токен в AppsFlyer [dashboard](https://support.appsflyer.com/hc/en-us/articles/360004562377-Managing-AppsFlyer-tokens).

### Шаг2

Применить зависимость модуля безопасности в файле Gradle вашего уровня приложения.
Обычно `<project>/<app-module>/build.gradle` или `<project>/<app-module>/build.gradle.kts` файл

```groovy
dependencies{
    // заменим <YOUR_APP_ID> своим App ID и <SECURITY_MODULE_VERSION> версией модуля безопасности   
    реализации 'com. ppsflyer.security:af-security-sdk-<YOUR_APP_ID>:<SECURITY_MODULE_VERSION>'
}
```

```kotlin
dependencies{
    // заменим <YOUR_APP_ID> своим App ID и <SECURITY_MODULE_VERSION> версией реализации модуля Security   
    . ppsflyer.security:af-security-sdk-<YOUR_APP_ID>:<SECURITY_MODULE_VERSION>")
}
```

## ЧАВО

В: Как узнать, какую версию модуля безопасности я должен использовать?
О: Вообще, вы должны использовать последнюю версию, доступную для вашего приложения, которая будет предоставлена вам в процессе посадки. Если вам нужен полный список доступных версий, пожалуйста, попросите контактного лица на AppsFlyer предоставить его вам.

В: Как мне получить новую версию модуля безопасности для моего приложения?
О: Пожалуйста, попросите вашего контактного лица на AppsFlyer отправить запрос на сборку от вашего имени, и мы предоставим вам новое имя версии для интеграции.

В: Если мне нужно повернуть токен AppsFlyer Maven Auth, как мне это сделать?
A: Пожалуйста, попросите вашего контактного лица на AppsFlyer повернуть ваш токен Auth AppsFlyer и мы предоставим вам новый токен.

## Создание отпечатка SHA256

### Debug

**Чтобы сгенерировать отпечаток SHA256:**

1. Найдите [магазин ключей приложения](https://developer.android.com/training/articles/keystore).
   При разработке вашего приложения используется хранилище ключей по умолчанию, если не указано другое в вашей конфигурации Gradle.
   По умолчанию `debug.keystore`:

- Для пользователя Windows: `C:\Users\USERNAME\.android\debug.keystore`
- Для пользователей Linux или Mac OS: `~/.android/debug.keystore`

2. Откройте командную строку и перейдите в ту папку, в которой находится файл keystore .
3. Выполнить команду:

```shell
// keytool -list -v -keystore KEY_STORE_FILE
// Например, файл keystore 
keytool -list -v -keystore ~/.android/debug.keystore
```

> 🚧 Пароль для debug.keystore обычно \"android\".

Вывод должен выглядеть следующим образом:

### Релиз

В этом случае необходимо предоставить хэш сертификата для ключа подписи **используемого Google**, используя эту опцию. Это **всегда** случай, когда вы распространяете наборы приложений для Android.</br>

1. В консоли Google Play найдите публичный отпечаток пальца SHA256 в **Настройке** -> **Регистрация приложения** (см. изображение ниже)
   ![](https://files.readme.io/8574437-Screenshot_2023-11-27_at_11.30.43.png)
2. Отправьте отпечаток пальца SHA256 в AppsFlyer.
