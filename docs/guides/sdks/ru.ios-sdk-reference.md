Это справочный документ для iOS SDK. В этом разделе вы найдете описание классов, протоколов и методов, которые входят в SDK.

## Уроки

- [AppsFlyerLib](doc:ios-sdk-reference-appsflyerlib): Этот класс содержит большую часть функциональности SDK
- [AppsFlyerDeepLinkResult](doc:ios-sdk-reference-appsflyerdeeplinkresult): Публичный интерфейс, который содержит метод обратного вызова для [Unified Deep Linking](https://dev.appsflyer.com/hc/docs/unified-deep-linking-udl).
- [AppsFlyerDeepLink](doc:ios-sdk-reference-appsflyerdeeplink): Объект с глубокими ссылками.
- [AppsFlyerCrossPromotionHelper](doc:ios-sdk-reference-appsflyercrosspromotionhelper): SDK кросс-промо-класс помощника.
- [AppsFlyerLinkGenerator](doc:ios-sdk-reference-appsflyerlinkgenerator): Объект используется для создания одноплатформенных и OneLink URL.
- [AppsFlyerShareInviteHelper](doc:ios-sdk-reference-appsflyershareinvitehelper): Помощь классу для создания приглашения пользователей.

## Protocols

- [AppsFlyerLibDelegate](doc:ios-sdk-reference-appsflyerlibdelegate): Delegate class that holds the callback method for OneLink legacy APIs and attribution.
- [AppsFlyerDeepLinkDelegate](doc:ios-sdk-reference-appsflyerdeeplinkdelegate): Делегировать класс, который содержит метод обратного вызова для [Unified Deep Linking](https://dev.appsflyer.com/hc/docs/unified-deep-linking-udl).
