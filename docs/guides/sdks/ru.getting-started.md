## Начало работы с AppsFlyer SDK

AppsFlyer расширяет возможности маркетологов и помогает им принимать лучшие решения.

Это делается путем предоставления маркетологам мощных инструментов, которые решают реальные больные точки. К ним относятся кросс-платформенная атрибуция, мобильная и веб-аналитика, глубокая связь, обнаружение мошенничества, управление и сохранение конфиденциальности и многое другое.

## Нативные SDK и плагины

Наборы для разработки программного обеспечения AppsFlyer (SDKs) и плагины являются вашим главным способом использовать нашу постоянно растущую экосистему услуг по цифровому маркетингу. [Интеграция наших SDK](https://dev.appsflyer.com/hc/docs/getting-started#integration-guides), вы получаете [attribution](https://support.appsflyer.com/hc/en-us/articles/207447053) вне коробки. Вы также получаете доступ к многим другим [возможностям SDK](https://dev.appsflyer.com/hc/docs/getting-started#sdk-features).

> 📘 Заметка
>
> AppsFlyer поддерживает только HTTPS протокол для всего входящего трафика SDK

### Нативные SDK
