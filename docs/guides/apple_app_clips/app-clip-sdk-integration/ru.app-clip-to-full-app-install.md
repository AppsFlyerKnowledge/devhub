Владельцы и рекламодатели могут присваивать пользовательские загрузки полного приложения из App Clip. Для этого разработчику необходимо настроить как клип приложения, так и полное приложение.
[block:api-header]
{
"title": "Процедуры"
}
[/block]
Для настройки атрибута App Clip-to-full app install в App Clip и полном приложении, следующий список действий по проверке процедур должен быть завершен.

**Важно**! Те же шаги должны выполняться как в клипе, так и в полном приложении.

{
"data": {
"h-0": "checklist",
"0-0": "1. В App Clip активируйте название групп приложений.",

"2-0": "3. В Клипе приложения обновите список информационных свойств (`info.plist` файл).",

},

"ряды": 4
}
[/block]

### Активировать права групп приложений

**Чтобы активировать права групп приложений**:

1. В Xcode, перейдите на страницу вашего проекта.
2. В разделе **Адресаты** выберите либо клип, либо полную цель приложения (в зависимости от конфигурации).
3. Нажмите на вкладку **Подписание и Возможности**.
4. Click **+Capability**.
   Открывается меню Возможностей.
5. В меню выберите группы приложений.

### Создать группу приложений

**Чтобы создать группу приложений для передачи данных между клиентом и полным приложением**:

1. В Xcode, перейдите на страницу вашего проекта.
2. В разделе **Адресаты** выберите либо клип, либо полную цель приложения (в зависимости от конфигурации).
3. Нажмите на вкладку **Подписание и Возможности**.
4. Во вкладке **Подписание и Возможности** перейдите в раздел **Группы приложений**.
5. Click **+**.
   Открывается окно **Добавить новый контейнер**.
6. В открывшемся окне введите имя вашей группы приложений, с следующей конвенцией именования:
   [block:code]
   {
   "codes": [
   {
   "code": "group. ourAppGroupName. ppClipToFullApp",
   "Язык": "текст"
   }
   ]
   }
   [/block]

### Обновить список информации

**Чтобы обновить список свойств информации (`info.plist` файл)**:

- В **Список свойств информации** (`info.plist` файл), добавьте строку с ключом и значением, как описано в следующей таблице.
  [block:parameters]
  {
  "data": {
  "h-0": "Ключ",
  "h-1": "Тип",
  "h-2": "Значение",
  "0-0": "AppsFlyerAppGroupName",
  "0-1": "Строка",
  "0-2": "Название, которое вы дали группе приложений на предыдущем шаге."
  },
  "холод": 3,
  "ряды": 1
  }
  [/block]

### Настроить полнофункциональное приложение

**Для настройки полного приложения**:

- Повторите все предыдущие шаги для полного приложения.
