События внутри приложения предоставляют рекламодателям возможность записывать после установки события (например, регистрации или покупок) с настраиваемыми деталями и присваивать их исходным медиа-источникам.

События внутри приложения для App Clips обычно происходят из внутри-приложений, настроенных для полного приложения. Поэтому, если события в приложении уже настроены для полного приложения, дополнительная работа для App Clip не требуется.

[Подробнее](https://dev.appsflyer.com/hc/docs/in-app-events-sdk) о добавлении событий в приложении для клипа и полного приложения.
