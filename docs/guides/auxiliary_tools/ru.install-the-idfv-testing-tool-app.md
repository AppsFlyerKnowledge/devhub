Приложение для тестирования IDFV позволяет AppsFlyer идентифицировать ваше устройство как тестирующее устройство, сохраняя IDFV (Identifier For Vendor) на всех последовательных установках.

## Зачем устанавливать приложение для тестирования IDFV?

Если вы неоднократно удаляете и переустановите приложение на устройство для тестирования, события установки не будут записаны, если вы [зарегистрируйте идентификатор устройства как принадлежащий тестирующему устройству в AppsFlyer](https://support.appsflyer.com/hc/en-us/articles/207031996-Registering-test-devices-).

Однако, когда тип идентификатора является IDFV (Identifier For Vendor) и протестированное приложение является единственным приложением на устройстве, связанном с поставщиком, значение IDFV будет заменено новым значением при каждом удалении и переустановке приложения. Следовательно, AppsFlyer не будет распознавать устройство как тестирующее устройство, потому что значение IDFV, используемое для регистрации устройства, было заменено другим значением.

Чтобы решить эту проблему, приложение для тестирования IDFV, устанавливаемое на тестовом устройстве, эмулирует, принадлежащий поставщику проверенного приложения. В результате зарегистрированное значение IDFV остается неизменным, даже если тестируемое приложение будет удалено и переустановлено.

## Как установить приложение для тестирования IDFV?

Чтобы включить приложение для эмуляции, принадлежащие тому же поставщику, что и протестированное приложение, должен быть подписан с значением IDFV поставщика, прежде чем он будет скомпилирован и установлен на тестируемом устройстве.

1. Клонировать [репозиторий приложений для тестирования IDFV](https://github.com/AppsFlyerSDK/my-idfv-by-appsflyer.git) на вашу локальную машину.
2. Откройте **Xcode** и выберите проект в **Project Navigator.**
3. В **ТАРЖЕ** выберите цель для вашего приложения для тестирования IDFV.
4. Раскройте раздел **Подпись**.
5. В **Bundle Identifier** введите идентификатор с идентичным префиксом к идентификатору приложения, которое вы тестируете.

   \*\*Например,\*\*если идентификатор вашего тестируемого приложения `com.MyCompany.apps.myapp`, вы должны изменить инструмент тестирования IDFV Bundle Identifier (`MyIDFVByAppsflyer`) на `com.MyCompany.apps.MyIDFVByAppsflyer`.
6. Создайте и установите инструмент тестирования IDFV на устройстве. Новое приложение получает тот же IDFV, что и ваше тестируемое приложение.
7. Запустите приложение для тестирования IDFV. Номер IDFV отображается в приложении. Вы можете использовать IDFV, когда [вручную зарегистрировать устройство в качестве тестового устройства](https://support.appsflyer.com/hc/en-us/articles/207031996#add-a-device-manually-via-the-user-interface).
